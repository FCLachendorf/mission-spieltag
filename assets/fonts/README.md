# Nunito

Gemeinsame Schrift für Oberfläche und Texte in der Spielwelt. Lokal geladen, keine Verbindung zu Google Fonts im Spiel.

Quelle: https://github.com/google/fonts/tree/main/ofl/nunito

Unveränderte Variable-Font-Datei Nunito[wght].ttf, hier als Nunito-Variable.ttf abgelegt. Lizenz: SIL Open Font License, siehe OFL.txt. Gewichte 200–1000; im Spiel werden insbesondere 400, 600, 700 und 800 verwendet.
